remora's fish is drawn in code today (`RemoraArt.swift`); exported as SVG, it would belong here too.

Rules the art follows, whatever the creature: flat shapes, ink (`#111111`) on off-white or off-white on ink, and lime only as a fill (`--accent`) or on dark, never as a line on a light background.
